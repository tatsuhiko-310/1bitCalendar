# 1bit Calendar

写真を2色のドット(1bit ディザ)に変換して、カレンダー入りのスマホ壁紙を作る Web アプリです。
処理はすべてブラウザの中で行い、写真をサーバーに送ることはありません。

A web app that turns a photo into two-color (1-bit dithered) dots and lays a calendar over it to make a phone wallpaper.
Everything runs in the browser; photos are never uploaded.

## 使い方

1. 写真を選ぶ(最初はサンプル画像が入っています)
2. プレビューをドラッグして写真やカレンダーを動かす。2本指(PC はホイール)で拡大・縮小
3. 「写真」「カレンダー」「色」タブで見た目を調整する
4. 「保存」で PNG を書き出し、端末の壁紙に設定する

## 主な機能

- **写真**: ドットの模様(格子 3 種・砂目 2 種・白黒のみ)、ドットの大きさ、明るさ、コントラスト、明暗の反転、トリミング
- **カレンダー**: レイアウト 7 種、フォント 7 種、週の始まり、言語(日本語 / English)、大きさ、枠と背景
- **色**: カラーテンプレート 8 種、色相・鮮やかさ・明るさのスライダー、カラーコードの直接入力、ドットと背景の入れ替え
- **配置**: ガイド(縦横の中央線)、スナップ(カレンダーと写真の辺・中央線に吸着)
- **確認**: 全画面表示
- **画像サイズ**: iPhone / Android / iPad / PC / 正方形。スマホで開くと、その端末の画面サイズを自動で選びます
- **その他**: UI の日本語 / 英語切り替え(初期は英語)、効果音の ON/OFF

## 動かし方

ビルドや依存パッケージはありません。`index.html` をブラウザで開くだけで動きます。

スマホで確認するときは、同じネットワークから見られるように簡単なサーバーを立てます。

```sh
npx serve .
```

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面の骨組み。文言は日本語で書き、英語は `app.js` の `EN` 表で置き換えます |
| `style.css` | 見た目。色は CSS 変数だけを使います |
| `app.js` | すべての処理。冒頭に目次があります |
| `CLAUDE.md` | 開発の方針(デザインのルールなど) |
| `docs/HANDOFF.md` | 初期の引き継ぎ資料(経緯の記録) |

## デザインのルール

- 画面の色は「ドットの色」と「背景の色」の 2 色だけ。半透明やぼかしで中間色を作らない
  (例外: 2 色が近くて見にくいときだけ出る「COLOR RESET」ボタン)
- カレンダーの色はドットの色と同じ
- 説明文は最小限にする

詳しくは `CLAUDE.md` を参照してください。
